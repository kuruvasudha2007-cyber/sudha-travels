Sudha Travels & TOURISM — 5 PAGE WEBSITE

FILES
1. index.html      Home
2. packages.html   Tour packages
3. booking.html    Booking form
4. gallery.html    Travel gallery
5. contact.html    Contact/about
6. style.css       Complete design
7. script.js       Menu, filters, booking/contact alerts, gallery lightbox

HOW TO RUN IN VS CODE
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html.
4. Recommended: install the VS Code "Live Server" extension.
5. Right-click index.html -> Open with Live Server.

IMPORTANT
- The booking/contact forms are front-end demo forms. They show a confirmation message but do not save data.
- Replace the phone, email and address in contact.html with your real business details.
- Replace the sample Unsplash image URLs with your own travel photos if desired.
- For real bookings, login/admin, database and online payment, a backend must be added later.
